Collapsed House by Nate Koenig / OpenRobotics: https://fuel.gazebosim.org/1.0/OpenRobotics/models/Collapsed%20house

`house-albedo.png` is a512×512 derivative of that house's albedo, with its original UV mapping retained in derived geometry. Rubble, boards, concrete and dust geometry are locally generated. Stone/wood material hues use the mean albedo and tint of the read-only local Gazebo reference; its source-resolution texture files are not distributed.

The scene is static. Small chips have conservative clustered contacts; see the world README for metrics and limitations.
