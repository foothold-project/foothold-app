# 2. 조이스틱 → 속도 명령

| 축 | 계산 | 끝까지 밀었을 때 |
|---|---|---|
| 전진 vx (왼 스틱 위) | ly × \|ly\| × 전진 상한 (제곱 곡선) | 1.2 m/s (`--fwd-max 1.2`) |
| 후진 vx (왼 스틱 아래) | ly × \|ly\| × 1.3 | -1.3 m/s |
| 옆 vy (왼 스틱 좌우) | lx × 0.8 (직선) | ±0.8 m/s |
| 회전 wz (오른 스틱 좌우) | rx × 1.5 (직선) | ±1.5 rad/s |

- 죽은 구간: 각 축 \|값\| < 0.05 는 0.
- 제곱 곡선이라 반만 밀면 전진 0.3 m/s (상한 1.2 기준).

# 3. 묶음 상한 (학습 범위에 맞춤 · core.cpp)

| 조건 | 상한 |
|---|---|
| 0.05 < \|vx\| < 0.3 에 옆이 섞이면 | vx 를 ±0.3 으로 올림 |
| 0.05 < \|vx\| < 0.3 에 회전이 섞이면 | 가장 큰 축만 남김 |
| \|vx\| > 0.6 이고 \|vy\| ≥ 0.2 | vx ±0.6 (대각) |
| 옆 vy | vx 0 → 0.8 · \|vx\| 0.3~0.6 → 0.5 · \|vx\| > 0.6 → 0 |
| 회전 wz | 제자리 1.5 · 후진이나 옆이 섞임 0.6 · 전진 0.3~1.2 → 1.0 · 전진 > 1.2 → 0 |

- 앉기: 발 맞추기 0.46 s → 기록 1.0 s → 끝 자세로 버팀.
- 발 맞추기: 순정은 앉기 전에 대각 두 발씩 「타탁」 두 번 디뎌 자기 서는 자세로 발을 옮긴다 (11/26 06:27:27 순정 기록: FL+RR 0.02~0.16 s · FR+RL 0.18~0.32 s · 앉기 시작 0.46 s · 한 번에 허벅지 +0.23 · 종아리 -0.42 rad 들어 올림). - 서기: 지금 자세 → 첫 줄 0.3 s → 기록 1.18 s → `default_pose` 로 0.5 s → 정책 게인으로 1 s → START 정책.
