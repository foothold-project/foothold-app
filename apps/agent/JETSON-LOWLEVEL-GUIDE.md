# Go2 X Jetson 저수준 정책 실행 안내

## 1. 한 줄로

Go2 는 원래 몸 안의 **순정 펌웨어 (모드 이름 `mcf`)** 가 걷기 · 서기 · 리모컨을 맡는다. 우리는 Jetson 에서 **실행기** 를 띄워
리모컨 「위 + start」 를 누르면 순정을 잠시 해제하고, 우리 START 정책 (ONNX) 이 1 초에 50 번 관절 목표를 계산해
모터에 직접 보낸다 (저수준 · LowCmd). 「← · → + start」 를 누르면 다시 순정에 돌려준다.

## 2. 누가 무엇을 하나

| 자리 | 하는 일 |
|---|---|
| Go2 몸통 (순정 펌웨어) | 모터 드라이버 · IMU · 리모컨 수신. 순정 모드일 때는 걷기까지. 저수준일 때는 받은 관절 목표를 PD 로 따라가기만 |
| Jetson (Orin NX) | 우리 실행기. 로봇 상태 (LowState) 를 받아 관측을 만들고 ONNX 를 돌려 관절 목표 (LowCmd) 를 보냄 |
| 리모컨 | 몸통이 받아 LowState 안의 `wireless_remote` 칸에 실어 보냄 → 실행기가 읽음 (순정이 꺼져도 들어옴) |
| 연결 | Jetson 의 로봇 쪽 랜 (`enP8p1s0`) 으로 DDS (CycloneDDS) · 주제 `rt/lowstate` (받기 · 500 Hz) · `rt/lowcmd` (보내기) |

| 문제 | 원인 | 처리 |
|---|---|---|

| SDK 의 CRC 파일 없음 | pip 설치가 `crc_aarch64.so` 를 빠뜨림 | 원본 묶음에서 복사 |

## 4. 실행기가 하는 일 (한 번의 「위 + start」)

1. **순정 모드 이름 읽기** (`CheckMode` → `mcf`). 돌아갈 때 이 이름을 쓴다.
2. **순정 해제** (`ReleaseMode` → `CheckMode` 가 빈 이름이 될 때까지). 이 순간부터 순정의 균형 · 넘어짐 방지가 꺼진다.
3. **지금 관절 각을 잡고 기본 자세로 2.5 초 보간** (PD 60/5 → 정책 PD 25/0.5 로 1 초에 걸쳐 바꿈). 서 있든 엎드려 있든 그대로 넘겨받는다.
4. **정책 루프**: 1 초에 50 번
   - LowState → 관측 45 (몸 각속도 · 중력 방향 · 명령 · 관절 각 · 관절 속도 · 직전 행동)
   - 이력 10 칸 · (복원 모드면) 깊이 두 장 · GRU 상태 되먹임 → ONNX
   - 행동 → 관절 목표 = 기본 자세 + 0.25 × 행동 (±17 자름) → 안전 상한 ±1.6 rad
   - LowCmd 는 1 초에 200 번 (정책 사이에는 마지막 목표를 다시)
5. **명령**: 리모컨 왼쪽 막대 앞뒤 · 좌우 = 앞뒤 · 옆 속도, 오른쪽 막대 좌우 = 회전. 시뮬과 같은 가감속 상한 · 중립 떨림 (0.05) 무시.

## 5. 리모컨 (팀장 11/22 정의 · 실기 확인)

| 조작 | 실행기 상태 | 동작 |
|---|---|---|
| 위 + start | 순정 · 감쇠 · 엎드림 | START 정책으로 넘겨받기 |
| 아래 + start | 어디서나 | AME-2 자리 (student ONNX 를 받으면) · 지금은 알림만 |
| ← + start | START | 천천히 엎드림 → 감쇠 → 순정 (`mcf`) → RecoveryStand → free walk |
| → + start | START | 같은 순서 → classic |
| L2 + A | START | 2 초 동안 천천히 엎드림 → 감쇠 |
| L2 + B | START | 즉시 감쇠 (비상 · 선 채면 털썩 주저앉음) |
| L2 + B | 순정 | 순정이 처리 (실행기는 아무것도 안 보냄) |

## 6. 안전 장치

- `--live` 와 승인 표식이 둘 다 있어야 보낸다. 없으면 dry-run (읽고 계산만 · 송신 0).
- LowState 가 50 ms 넘게 끊기면 감쇠.
- 몸이 60° 넘게 기운 상태가 0.5 초 → 감쇠 → 순정 → RecoveryStand (실기 미확인).
- 순정 복귀는 `CheckMode` 로 붙었는지 확인 · 5 번 다시 · 끝내 안 붙으면 감쇠하고 알림 (성공이라 적지 않음).

## 7. 실기에서 겪은 일과 고친 것 (11/22)

| 겪은 일 | 원인 | 고침 |
|---|---|---|
| 순정 복귀 뒤 L2 + A 가 안 먹고 로봇이 모드 없이 엎드림 | SDK 예제 이름 `normal` 을 이 펌웨어가 거절 (7004) · 결과를 확인 안 함 | 해제 전 읽은 이름 (`mcf`) 으로 · 결과 확인 |
| 선 채로 넘겨받아 앉는 단계가 안 보임 | StandDown 직후 바로 해제 | 지금은 어떤 자세에서든 바로 넘겨받는 것이 기본 (팀장 결정) |
| START 상태에서 순정 복귀 때 뒤집힘 | 감쇠 먼저 → 순정이 붙는 4 초 동안 힘 빠짐 | 먼저 천천히 엎드린 뒤 넘김 |
| 순정 복귀 때 모터 갈리는 소리 | 실행기와 순정이 잠깐 같이 모터를 쥠 | 엎드려 감쇠한 뒤 넘겨 겹침 없음 |
| classic 을 골라도 sport 로 붙음 | 일어서는 중에 보행 전환을 보냄 | 3 초 뒤 보냄 |
| 출발이 툭툭 튀어나감 | 막대 값을 그대로 명령으로 | 시뮬과 같은 가감속 |
| 중국어로 바뀜 | 미확인 (전원 재시작으로 영어로 돌아옴) | |
