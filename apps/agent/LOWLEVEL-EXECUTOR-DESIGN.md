# apps/agent 저수준 정책 실행기 설계 초안

## 1. 무엇을 · 어디에

- 자리: 이 저장소 `apps/agent` (팀장 11/19 01:27 결정). 새 패키지 이름 후보 `foothold_agent/lowlevel/`.
- 하는 일: 정책별 contract 를 읽어 LowState (관절 q · dq · IMU · `wireless_remote`) 와 깊이 · 지도 입력을 정책 입력 벡터로 맞추고, ONNX 를 돌려 나온 관절 목표를 LowCmd (q · Kp · Kd) 로 바꾼다.
- 하지 않는 일: 명령 주인 · STOP · 조종권 (lease) 을 새로 만들지 않는다. 지금 `go2_direct/sink.py` 의 출처 하나 · STOP 우선 · 0.3 초 끊김 hold 틀에 새 출처 · 새 모드로 들어간다 (방향 문서 3 절).
- 정책: 실행기 하나가 contract 로 입력을 바꾼다 (START 몸감각 45 + 깊이 · AME-2 몸감각 49 + 지도 29x13x3). 앱 시뮬 `mobile/sim/policy-onnx.js` 와 같은 꼴.

## 3. 단계 (앞 단계를 통과해야 다음으로)

| 단계 | 로봇에 무엇이 가나 | 하는 일 | 통과 기준 (초안 · 팀장이 정함) |
|---|---|---|---|
| 1. offline parity | 없음 (로봇 없이) | 같은 입력 기록을 앱 시뮬 (onnxruntime-web) · 학습 쪽 (PyTorch / ONNX) · agent 실행기에 넣어 행동이 같은지 | 행동 벡터 최대 차가 정한 값 아래 · 관절 순서 · 부호 · 배율 일치 |
| 2. read-only shadow | 없음 (receive-only) | 실기 LowState 를 받아 실행기를 돌리되 LowCmd 는 만들기만 하고 보내지 않는다. 순정 Sport 로 서 있거나 걸을 때 정책이 낼 명령을 기록 | 주기 지연 · 입력 빠짐 · 깊이 끊김이 정한 값 안 · 명령이 관절 한계 안 · 열 · 배터리 감시가 기록과 맞음 |
| 3. 매달기 | 관절 명령 (공중) | 몸을 매달아 발이 땅에 닿지 않게 하고 낮은 Kp 부터 | 안전 정지 (L2+B · 앱 · 통신 끊김) 가 매번 듣는지 · 관절 추종 · 온도 오름 |
| 4. 평지 map_off | 관절 명령 (땅) | 평지에서 지도 입력 끈 판 (몸감각만) | 서기 · 제자리 · 짧은 직진 · 회전 · 멈춤이 시뮬과 같은 꼴 |
| 5. map_on | 관절 명령 (땅) | 깊이 · 지도 입력을 켠 판 | 4 와 같음 + 지형 입력이 시뮬 카메라 정의와 맞는지 (lab 8 절 5 번) |

- 1 · 2 단계는 로봇에 관절 명령을 보내지 않는다. 그래도 2 단계 전에 receive-only 장시간 기록을 먼저 켠다 (방향 문서 5b 의 Stand 전 규칙).
- 3 단계부터는 로봇 명령이므로 팀장 동의 아래에서만 한다 (방향 문서 1 절).

## 4. 실기 관문 (3 단계 「매달기」 부터 · 셋 모두 통과해야 한다)

1. **업체 열 판정**: 11/18 앞 hip 78 · 81 °C · 11/19 RR hip 71 °C 와 reserve ≠ 0 · 적색 점멸 두 사건에 대한 업체 답. 답이 오기 전에는 저수준 정책을 실기에 보내지 않는다. 온도 문턱 (50 주의 · 60 경고 · 70 위험) 과 70 °C 자동 멈춤 여부도 이 답을 본 뒤 팀장이 정한다.
2. **조이스틱 비상 정지**: 저수준 모드에서 순정 L2+B 가 듣는지는 미확인이다. 실행기가 `wireless_remote` 의 L2+B 를 직접 읽어 안전 정지 (Kp 0 · Kd 만) 로 가는 것을 2 단계 shadow 에서 기록으로, 3 단계 처음에 실제로 확인한다. 앱 STOP · 통신 0.3 초 끊김도 같은 안전 정지로 간다.
3. **두 사람 매달기**: 한 사람은 조이스틱 (L2+B) 을 들고, 한 사람은 매단 몸과 줄을 잡는다. 둘이 없으면 3 단계를 시작하지 않는다.

## 5. 멈추는 법 (방향 문서 4 절과 같음)

- 멈춤: 정책은 계속 돌고 명령만 0 → 제자리에 섬.
- 안전 정지: 정책 송신을 끊고 Kp 0 · Kd 만 → 천천히 앉음. 들어가는 경우: L2+B · 앱 STOP · 입력 0.3 초 끊김 · 출력 NaN · 관절 한계 넘음 · reserve ≠ 0 (이 마지막은 팀장 결정 대기).
- 되돌리기: 안전 정지 → Sport 서비스 켜기 → 일어서기 (사람 확인 뒤).

## 6. 정할 것 (팀장)

- 각 단계 통과 기준의 숫자 (parity 차 · 지연 · Kp 시작 값).
- 70 °C 또는 reserve ≠ 0 에서 자동 안전 정지할지 (업체 답 뒤).
- 우리 모드 핫키 조합 (순정 조합과 겹침 검사 먼저).
- 실행기 서비스는 자동 시작하지 않고 손으로 켠다 (작업자 현민과 맞출 것).
