휴대폰 주소

같은 Wi-Fi 이면 첫 주소, 밖에서는 Tailscale 을 켜고 둘째 주소. 로그인은 운영 앱과 같은 계정입니다.

주소 읽는 중…

iPhone — 처음 한 번

  1. 인증서: 휴대폰에서 ca.crt 받기 → 설정 › 일반 › VPN 및 기기 관리에서 프로파일 설치 → 설정 › 일반 › 정보 › 인증서 신뢰 설정에서 «Go2 control app local CA» 켜기. 운영 앱(8443)에서 이미 했다면 건너뜁니다(같은 인증서).
  2. Safari 로 위 휴대폰 주소를 열고 로그인합니다.
  3. 공유 버튼 → «홈 화면에 추가» → «웹 앱으로 열기» 켜고 추가.
  4. 홈 화면의 FOOTHOLD 아이콘으로 열면 주소창 없는 가로 화면입니다. 로그인 화면이 나오면 한 번 더 로그인합니다(iOS 판에 따라 Safari 로그인이 이어지기도 합니다).

조종 화면의 ⛶ 버튼은 브라우저가 전체화면을 지원하면 전체화면으로, 지원하지 않으면 안내를 띄웁니다. 그때는 홈 화면 웹 앱으로 쓰면 주소창이 없습니다.
