## 2. 단순화 원칙 (10-19 점검 결과 반영)

| # | 원칙 | 지금 문제 (근거) | 판정 기준 |
|---|---|---|---|
| U1 | **로봇부터 고른다** | 페이지 전체 로봇 전환 + 새로 고침 → 모든 작업 앞에 "고르기" | 로봇 행 누름 → 서랍에서 그 로봇의 모든 행동 |
| U2 | **상태는 문제가 있을 때만** | 칩 3개 + ? + 상태▾ + HTTP 404 글이 모든 머리줄 | 정상일 때 머리줄 상태 표시는 점 하나 |
| U3 | **한 개념은 한 화면** | 임무 3곳, 지도 편집 2곳, 폰 탭 두 벌 | 기능마다 들어가는 곳 1개 |
| U4 | **이름표로 뜻이 통하게** | ? 도움말이 조종 화면에만 7개 | 화면당 ? 도움말 1개 이하 |
| U5 | **운영 화면에 개발 용어 금지** | 관문·링크·명령 0·deadman·Gazebo·GT·HTTP 404 | 아래 금지어 0회 (개발자 모드 제외) |
| U6 | **역할은 단추만 바꾼다** | — | 같은 화면 틀. 권한 없으면 자물쇠/승인 요청 |
| U7 | **누름 대상 44 px, 글자 14 px** | 44 px 미만: PcPlan 29개, PcMap 24개 | 운영 화면 44 px 미만 0개, 폰 STOP 64 px |
| U8 | **오류 문구 = 무엇이 + 어떻게** | "서버에 없음 (HTTP 404)" | 오류 문장마다 다음 행동 1개 |
| U9 | **값이 없으면 숨긴다** | "미제공·미연결" 줄이 연달아 | 없는 값 줄 연속 2줄 이상 0 |
| U10 | **확인창은 되돌릴 수 없는 일에만** | — | 확인창: 조종 시작, 실행 시작, 결재 반려, 지도 판 되돌리기, 긴급 실행 |

## 4. 상태 표시 하나로 통일
- 모양: `[모양 아이콘][짧은 글 12자 이하]`. 색: off(회색) · ok(초록) · warn(주황) · bad(빨강).
- 색 규칙: **회색** = 일부러 꺼짐·값 없음, **주황** = 운영 중 나빠짐, **빨강** = 잠금·경보·끊김.
- 자세한 이유는 누르면 열리는 작은 창에. 화면 본문에 설명 문단을 두지 않는다.
- 색만으로 구분하지 않는다(모양 아이콘 + 글자 함께, 색각 이상 대비).

```

│ ● Go2-3  82% 2층순찰 3/5││                                ││ Go2-3  ● 임무 중 │
│ ▲ Go2-7  15% 대기       ││     ▶Go2-3 ·····              ││ [조종하기][배정] │
│ ○ Go2-1  —  끊김        ││                                ││ 위치 (작은 지도) │
│ 🔒 Go2-9 (박OO)          ││                                ││ 현재 임무 3/5    │
│                         ││                                ││ 배터리·장치      │
│                         ││                                ││ 그래프           │
│                         ││                                ││ 최근 사건        │
│                         ││                                ││ ▸ 고급           │
```

### 5.2 조종
```
┌ Go2-3 · 조종 중(나) · 0.4 m/s · 지연 85 ms · 82% ───── [조종 끝내기] ┐
│ ┌──────────────────────────────────────────────┐                      │
│ │                                              │  [RGB][뎁스][지도 크게]│
│ │              RGB 영상 (크게)                  │                      │
│ │                                ┌──────────┐ │                      │

│ │        (마우스 막대: 영상 위)    └──────────┘ │                      │
│ └──────────────────────────────────────────────┘                      │
│ 시나리오 실행 중: 2층 순찰 3/5 ▓▓▓▓▓░░░  [일시정지][중단]               │
└───────────────────────────────────────────────────────────────────────┘
```
- 할 일 접기 3개·사건 기록 칸은 없앤다. 사건은 기록 탭과 알림으로.
- 조종권 요청 창은 화면 가운데 위, 영상 일부만 가린다. 10 s 막대 표시. 단추는 마우스·터치로만.

## 6. 누름 수 예산 (인수 기준)
| 작업 | 지금 | 목표 |
|---|---|---|
| 로봇 X 위치·상태 보기 | 3+ | 1 |
| 로봇 X 조종 시작 | 6 | 조종권 받기 3 (행 → 조종하기 → 조종 시작), 움직일 수 있는 상태까지 4 (+ 잠금 해제) |
| 시나리오 만들어 배정 | 7+ (배정 불가) | 지도 1 + 지점 n×2 + 저장 1 + 배정 2 |
| 실패 원인 찾기 | 5~6 | 2 |
| 폰 시나리오 실행 | ~10 | 2 |
| 결재 1건 처리 | — | 2 (항목 → 승인) |

## 7. 접근성·기기
- 대비: 본문 4.5:1 이상(브랜드 토큰 대비값 유지).

- 화면 너비 768 px 미만 = 폰 틀.
