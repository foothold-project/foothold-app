# 시안 그대로 UI 구현 — 진행 기록

기준: 디자인 시안 10개 화면을 원본 그대로 구현합니다. 기능 연결은 UI를 확정한 다음에 합니다.
화면 속 값은 모두 예시 데이터입니다. ROS·실제 로봇·실제 임무와 연결되어 있지 않고, STOP 버튼은 모양만 있는 시안입니다.

## 2. 구현 방식

- `web/<화면>.dc.html` = 원본 파일 그대로입니다. 다른 곳은 실행 스크립트 3줄(react, react-dom, support.js)을 `<script src="./dc.js">` 1줄로 바꾼 것뿐입니다(diff 4줄).
- `web/dc.js` = 직접 만든 실행기(React 없음). 시안 10개에 쓰인 문법만 지원합니다:
  - `{{경로}}`
  - `sc-if`, `sc-for`
  - `on*` 이벤트
  - `setState`
- 원본 실행기와 동작을 맞춘 점:
  - 글 속 값은 `span.sc-interp`로 감쌉니다. 이 차이로 flex 간격이 달라집니다.
  - null과 true/false는 그리지 않습니다.
  - `<select value>`는 해당 항목을 고릅니다.
  - 값이 바뀌면 커서를 끝으로 옮깁니다.
  - SVG `<text>` 안의 값은 그리지 않습니다(Q3).
- `web/index.html` = 화면 목록과 «예시 데이터» 안내입니다.

## 4. 미결 — 사용자 결정 전까지 원본 그대로 둡니다

- **Q1 조종 막대 배치**
  - 시안 기본값은 «왼쪽 이동(앞뒤·옆) · 오른쪽 회전»입니다.
  - 기존 요청은 «왼쪽 회전 · 오른쪽 앞뒤»였습니다.
  - 시안에는 두 배치가 모두 있습니다(`?stickLayout=`). 기본값은 바꾸지 않았습니다.
- **Q2 예시 기능을 계속 예시로 둘지**: 5초 통신 끊김 후퇴, 가스·AI·긴급 경보.
  - 문구와 배치는 그대로 두었습니다.
  - 실제 기능으로 연결하지 않았습니다.
- **Q3 지도 위 글자가 빈칸**: Main·PcPlan 지도 SVG의 태그 이름과 θ가 원본 시안 실행기에서도 빈칸입니다. SVG `<text>` 안에 span을 넣는 방식 때문입니다. 구현도 원본과 똑같이 빈칸입니다.
- **Q4 Main 아래 남은 문장**
  - Main 파일 끝, 화면 틀 밖에 «분야는 미정이다. 단계마다 다음 기준이 정해지지 않은 임무는 실행하지 않는다: …» 문단과 남는 `</div>`가 있습니다.
  - 아래로 스크롤하면 화면 틀 밑에 보입니다. 원본도 같습니다.
- **Q5 예시 이름·법규 문구**
  - 운영자 이름 «김도윤»이 Main·PcMissions·PcReview·Report에 나옵니다.
  - Report에는 «산업안전보건기준에 관한 규칙 제618조»와 «OSHA 29 CFR 1910.146 준용»이 나옵니다.
  - 공개 저장소에 그대로 둘지 확인이 필요합니다(예시 표본인지, 실제 인물인지).
- RGB 차이가 16 이하인 픽셀은 세지 않았습니다. 그래서 위 결과를 픽셀까지 완전히 같다는 뜻으로 쓰지 않습니다.

- **Q6 Main STOP 위치 (Codex 확인)**: Main을 1440×920으로 보면 STOP이 줄바꿈되어 왼쪽 아래로 내려갑니다. 디자인 시스템의 기준(오른쪽 위)과 다릅니다. 원본도 같습니다. Q3·Q4와 함께, 이 3건만 고칠지 사용자 답을 기다립니다.
- **링크 빈자리 (`href="#"`)**
  - PC 4개 화면에는 왼쪽 메뉴의 아직 없는 항목이 각각 3개씩 있습니다. Main에는 «기준 설정» 1개가 더 있습니다.
  - MHome에는 2개 있습니다.
  - 지도·로봇·설정 같은 하위 화면은 시안에 없어서 만들지 않았습니다. 앞으로 만들 기능으로 남깁니다.
- 글꼴을 오프라인에 둘지, `reference/`를 저장소에 넣을지(support.js 라이선스), 저장소 라이선스: 모두 미정입니다.

## 5. Git

- 원격: 비어 있는 공개 저장소입니다. AGENTS·CONTRIBUTING·.github·템플릿 없음, rulesets `[]`, 라이선스 없음.
- 이 계정의 권한은 pull만 있고 push는 없습니다.
- 브랜치 `feature/ui-reference-oh`에 로컬 커밋만 합니다. 이 저장소에만 작성자를 GitHub noreply 주소로 설정했습니다(전역 git 설정은 그대로).
  - push와 PR은 권한, 실제 GitHub 규칙, 최종 내용 검수가 모두 갖춰진 뒤에 합니다.
  - main에 직접 push하거나 force하지 않습니다.
- 커밋 대상: `web/`, `tools/`, `docs/`, `README.md`, `.gitignore`. 제외: `runs/`, `reference/`.
