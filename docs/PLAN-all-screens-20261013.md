# 모든 화면 실연결 계획 (2026-10-13, 앱 Codex 검수 보완 반영)

목표: 앱(휴대폰)·웹(PC) 시안 화면을 **현재 v2 연결로 할 수 있는 일은 모두** 실제로 동작하게 한다.
안 되는 일은 로봇 고유 한계로 단정하지 않고 «현재 v2 연결에서 미제공 / 미연결 / 미검증»으로 구분해 표시한다
(예: 배터리 = v2 시뮬 상태에 값 미제공 — Go2 에 배터리가 없다는 뜻 아님 · 자동 이동 = Nav2 미연결).

## 기준
- 좌표: Gazebo GT(시뮬 정답 위치). 지도 = 시뮬 바닥 도면(평평 ±10 m, 1 m 격자). SLAM·장애물 관측 아님을 화면에 적는다.
- 지도(관제·조종 미니맵·휴대폰 지도·PC 지도·계획)는 **공용 그리기 하나**. 기본 북쪽 위 · 로봇 중심(지도가 움직임).
  손으로 끌면 따라가기 해제 → «로봇 중심» 버튼으로 복귀 · «전체 보기».
  GT 가 없거나 1 s 넘게 오래되면 마지막 위치를 흐린 «오래됨» 표시(가짜 위치 없음). 바닥 ±10 m 밖 위치는 경계에 가두지 않고 «도면 밖»으로 그린다.
- 공용 문서 저장(v2_link): 종류별 형식 검사(글 길이·유한 숫자·개수), 서버가 ID·판(rev) 생성, 임시 파일→원자 교체.
  PC·휴대폰 동시 편집은 rev 대조 — 어긋나면 409 «다른 기기가 먼저 고침» 안내, 내 초안은 화면에 보존. 문서 수정은 로그인만 필요(로봇 조종권과 분리).
- 금지·감속 구역은 그리기·저장·공유 기능. **실제 주행 제한은 미연결**(충돌·감속 보장 없음)을 화면에 명시.
- 사진 = 운영자 등록 관찰. 분류 «확인 · 보류 · 제외» + 메모. AI 탐지가 없으므로 «맞음/오탐»이라 부르지 않는다.

## 단계
| 단계 | 화면 | 내용 |
|---|---|---|
| 1 | Main·MDrive 지도, MMap, PcMap | 공용 지도, 지도 창 열기, 구역 그리기·저장·공유 |
| 2 | PcMissions, PcPlan, MHome | 임무(경유점·할 일) 만들기·고치기·복제·삭제 + **수동 임무 진행**: 시작 → 직접 조종·현장 확인 → 경유점별 방문/미방문 사유·사진·메모 → 완료·실패·중단 → PC·폰 공유 결과. 자동 목적지 이동·자동 복귀는 미연결·실행 안 함, 수동 확인을 로봇 자동 완료로 표시하지 않음 |
| 3 | MAlerts·MAlert, MHistory, PcHistory, MFinding, PcReview, Report | 서버 사건·사진 기반 알림·기록·관찰 분류·임무 결과, 보고서 인쇄·CSV |
| 4 | PcRobot, PcSettings | 실제 상태값, 미제공·미연결·미검증 구분, 화면 설정 |

공통: 탭 이동·뒤로·회전·숨김에서 누름 정리, 모든 화면에서 STOP 접근, 새 판 반영 시 새로고침 안내(판 섞임 방지).
시안의 예시값은 실측·기록처럼 보이지 않게 지우거나 «미연결»로 바꾼다. System(디자인 시스템)은 그대로.

## 하지 않는 것
- 자율 이동·경로 추종·자동 복귀 · 가스/탐지 값 만들기 · 실기 Go2 · SLAM/Nav2 기동 · 새 Pod/학습 · 시뮬 자동 기동.
- 사용자가 조종 중일 때 서빙 판 교체.
