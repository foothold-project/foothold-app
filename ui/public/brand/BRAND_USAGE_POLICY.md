# Brand asset usage policy

## Official assets

Only files indexed by [`assets/exports/v1/manifest.json`](./assets/exports/v1/manifest.json) and the canonical logo files in [`assets/logo/v1`](./assets/logo/v1/) are approved v1 assets. Files under `concepts/` document review history and are not official assets.

## Do

- use the provided light, dark, monochrome, compact, primary, or stacked variant appropriate to the surface;
- preserve the approved wordmark visible aspect ratio `7.841215388`;
- preserve clear space and legibility;
- use the subtitle `Terrain-Adaptive Locomotion Policy` only in lockups that include a subtitle;
- keep semantic colours tied to their documented meanings.

## Do not

- regenerate the approved logo or subtitle from a locally installed font;
- stretch, rotate, outline, add glow, recolour arbitrarily, or rearrange the mark;
- use `concepts/` review images as current identity assets;
- present a Figma-only experiment as an approved Git asset;
- infer performance, deployment, partnership, team-role, or safety claims from the branding.

## Change path

Brand changes follow `Figma proposal -> JSON/SVG/PNG handoff -> repository diff -> human approval -> canonical promotion -> regenerated derivatives`. Direct edits to derived exports do not create a new canonical version.
