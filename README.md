# foothold-app

현재 앱은 `ui/`의 React 화면과 인증 관문(`sim/v2_gate.py`)·연결 서버(`sim/v2_link.py`)를 사용한다. 아래의 `web/` 시안과 초기 연결 기록은 이전 구현 자료다. 시안용 값과 실제 연결 상태를 구분하며, 실 Go2·다중 로봇 물리 리허설·자동 이동의 성공을 뜻하지 않는다.

새 리허설 작업은 PC 전체 관제 `#/Fleet`, 지도 편집 `#/MapEditor`, 휴대폰 현장 `#/Field`를 추가한다. 빈 주소의 첫 입구만 PC/휴대폰에 맞추며 기존 `#/Main`·`#/MDrive` 등 명시한 화면과 제어 경로를 유지한다. 편집·저장·2D 기하 검토·세계/지도 묶음 생성은 로봇 명령이나 Gazebo 기동을 하지 않는다.

- [새 화면과 자료 보관·기능 범위](docs/REHEARSAL.md)
- [리허설 API·JSON·상한 계약](docs/CONTRACT-rehearsal.md)

소스 변경, 운영 웹 반영, APK 빌드는 각각 별도로 검증한다. APK에 서버 코드가 들어가는 것은 아니며, 실제 휴대폰/WebView와 물리 실행의 미확인 사항을 구조 검사 결과로 대신하지 않는다.

## 기존 웹 구현 기록

현장에서 로봇을 조종하고, 임무를 맡기고, 결과를 기록하는 앱의 **화면 시안 구현**입니다.

> **예시 데이터입니다. 실제 로봇 상태가 아닙니다.**

> - STOP 버튼은 모양만 있는 시안입니다. 아무것도 멈추지 않습니다.

## v2 시뮬 실연결 (`?live=v2`)

관제(`Main.dc.html?live=v2`)·조종(`MDrive.dc.html?live=v2`)은 시뮬 조종에, 그 밖의 PC·휴대폰 화면(`?live=v2`)은 아래 «임무·지도 화면» 표의 공유 문서 기능에 연결합니다. Gazebo·정책·RESET 은 RL 쪽 세션이 띄우고, 이 앱은 Gazebo 를 띄우지 않습니다. `?live` 가 없으면 시안 그대로입니다.

```bash

source /opt/ros/jazzy/setup.bash
export ROS_DOMAIN_ID=61 ROS_AUTOMATIC_DISCOVERY_RANGE=LOCALHOST
python3 sim/v2_link.py --port 8790          # 끝낼 때 Ctrl+C (끝나며 명령 0 한 번)
# 브라우저: http://127.0.0.1:8790/MDrive.dc.html?live=v2  · http://127.0.0.1:8790/Main.dc.html?live=v2
```

- 계약 정본: `control-app/experiments/33-foothold-v2-gazebo-20261012/online-20261012/CONTRACT-v2_live.md`. 127.0.0.1 전용, 같은 출처(8790)의 페이지만 WebSocket 을 열 수 있습니다.
- 안전 판단은 서버(`sim/v2_link.py`)가 합니다. 조종권은 한 기기만, 막대를 처음 누르면 조종권만 얻고 다시 눌러야 움직입니다.
- 보내는 명령은 시험한 값뿐입니다: 0 · 앞 0.6 m/s · 앞 0.6 + 회전 ±0.5 rad/s. 후진·옆걸음·제자리 회전·저속은 «미검증»으로 표시하고 보내지 않습니다.
- 손을 떼거나, 입력이 0.3 s 끊기거나, 화면을 숨기거나, 연결·시뮬 상태가 끊기면 명령은 0 입니다. 다시 이어져도 예전 입력을 되살리지 않습니다.
- STOP 은 누구나 누를 수 있고 명령 0 을 잠급니다. 시뮬은 기동·리셋 뒤에도 STOP 상태입니다. «조종 시작»(확인 1회 = 조종권 받기 + STOP 해제, 10-15 N1) → 시뮬 확인 → 새로 누름 순서로만 다시 움직입니다. 확인창을 연 뒤 STOP·잠금이 한 번이라도 있었으면 서버가 해제를 거부합니다(잠금 세대 `stop_gen`). RESET 도 STOP 을 유지합니다.
- 표시: 위치·속도·기울기·넘어짐은 Gazebo 정답값(GT)이고 지도가 아닙니다. 카메라는 Gazebo 렌더입니다. 배터리·지도·임무·AI·가스는 «미연결»입니다. 시험 문구 «Gazebo · foothold-v2 시험 · 낙상·정지 지연 미검증»과, 정지 뒤 1~2 s 안에 한 번 다시 움직일 수 있다는 주의를 함께 보입니다(시뮬 기록 최대 약 .33 m/s·28°).
- 시험: `python3 sim/v2_link.py --selftest`(ROS 없이) · `tools/live_check.py`·`tools/live_ui_check.py`(가짜 발행기 domain 88 + 포트 8791 모의, 실제 근거 아님) · `tools/live_e2e.py`·`tools/live_probe.py`(이미 떠 있는 실연결 서버 대상).
- 시험(두 기기): `tools/gate_check.py`(시험 계정·시험 인증서 임시 폴더 + 관문 8463/8464 모의, 실제 `.gate`·실아이폰 근거 아님).
- 진입: `index.html` 맨 위 «v2 시뮬 실연결» 두 링크(8780 미리보기에서 열면 8790 주소로). `?live` 없이 열면 «시안 · 동작 안 함» 안내와 실연결 링크가 뜹니다.

### 휴대폰·다른 PC 에서 열기 (보호 관문 `sim/v2_gate.py`, https 8453)

```bash
# 로컬 ROS PC, foothold-app 폴더에서 (v2_link 8790 이 떠 있을 때)
python3 sim/v2_gate.py --bind 0.0.0.0 --port 8453
# PC: https://<PC 주소>:8453/  · 휴대폰: 같은 주소(휴대폰이면 조종 화면) · 안내: https://<PC 주소>:8453/start.html
```

- v2_link 를 다른 포트로 띄웠다면 관문에 `--upstream 127.0.0.1:<그 포트>` 를 줍니다(기본 8790).
- 8790 은 계속 127.0.0.1 전용입니다. 관문만 밖에 열리고, 로그인한 세션만 화면·사진·기록·WebSocket 을 8790 으로 중계합니다.
- 계정·인증서는 운영 앱(8443) 관문의 `control-app/.gate` 를 **읽기만** 합니다(새로 만들지 않음, 없으면 기동 거부). 쿠키 이름은 `fh2_s`·`fh2_dev` 라 운영 로그인과 섞이지 않습니다.
- 관문이 «계정 · 기기 이름»을 붙여 v2_link 에 넘깁니다(화면이 고칠 수 없음). 로그아웃·12 h 만료·탭 닫힘 → 조종권 해제 · 명령 0 · STOP 잠금.
- 홈 화면 웹 앱: `start.html` 의 안내대로 인증서 신뢰 → 홈 화면에 추가(가로·주소창 없음). 실제 iPhone 확인은 아직입니다.
- «시뮬 시작(30분)»: `--sim-start <RL request_session.sh>` 로 v2_link 를 띄웠을 때만. 시뮬이 꺼져 있을 때만 보이고, 확인 창 → RL 래퍼 1회(120 s 쿨다운·동시 1건·재시도·연장 없음). 결과는 기록에 남고, 상태·영상이 들어오는지는 화면 표시로 판단합니다(안전 준비 판정 아님). 남은 시간은 RL `session_status.sh` 원값.

### 임무·지도 화면 (서버 공유 문서, 모의 시험만)

원본 시안 화면을 그대로 두고 실데이터를 채웁니다. 저장은 서버 공유 문서(판 번호 · 다른 기기와 충돌하면 409, 내 초안은 화면에 남음)이고 로그인만 필요합니다(조종권과 무관).

| 구분 | 내용 |
|---|---|
| 구현 | 수동 임무 양식(PcMissions) · 계획: 지도를 눌러 지점 추가·저장(PcPlan) · 수동 진행: 방문 확인·미방문 사유·지점 사진·운영자 확인/보류/제외(Main·MHome) · 관찰 사진 분류: 확인·보류·제외 + 메모(MFinding·PcReview) · 기록·CSV(PcHistory·MHistory) · 보고서(Report) · 구역 그리기·저장·공유(PcMap, 표시만) · 지도는 북쪽 위·로봇 중심 기본 |
| 미연결 | SLAM 지도·위치 맞추기 · Nav2 목표 이동·자동 복귀 · 구역의 실제 주행 제한(표시·공유만) · 실기 Go2 · AI 판독 · 가스 측정 |
| 검증 | 가짜 발행기(domain 88)·포트 8791 모의 + headless Chrome 시험만. 실제 iPhone·현장 미확인 |

- 수동 임무는 자동으로 이동하거나 자동으로 끝나지 않습니다. 지점 도착은 운영자가 «방문 확인»으로 기록합니다.
- 위치는 Gazebo 정답값(GT)이며 SLAM 위치가 아닙니다.
- STOP 은 명령 0 요청 + 잠금입니다. 몸 정지는 별도이며, 시뮬에서 STOP 뒤 약 3.6 s 동안 0.32 m 더 움직인 관측이 있습니다(원인 미확인).
